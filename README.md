### Problem Statement
In India, during medical emergencies, people waste crucial 15-20 minutes searching for help, sharing location, and finding correct first-aid. Unsafe roads and unsafe areas for women go unreported due to lack of a simple reporting tool.

### Solution - JeevanSetu
A lightweight, offline-first, single-platform solution:

1.  **One-Tap SOS:** Captures live GPS, calls 112, shares live location via WhatsApp to trusted contacts.
2.  **AI First-Aid Assistant:** Step-by-step guidance for CPR, heart attack, bleeding, snake bite - built with AI prompt engineering.
3.  **Public Safety Reporting:** Report potholes, black spots, unsafe areas with photo + GPS. Saved securely in LocalStorage (offline works).
4.  **Trusted Contacts:** Save family contacts for instant emergency sharing.

### Tech Stack (Current - No Backend)
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Storage: Browser LocalStorage (Offline-First)
- APIs: Geolocation API, Web Share API, Google Maps Link
- AI Tools Used: ChatGPT (for UI logic), Gemini (for first-aid content structuring), Copilot (for JS functions)

### Future Scope
This current version is intentionally built without any backend to ensure speed and 100% offline functionality. In next phase, it can be scaled with:
- Node.js + Database for community reports
- AI Voice Assistant in Hindi/English
- Live Safety Heatmap for Smart City Dashboard
- Integration with ERSS 112 System
